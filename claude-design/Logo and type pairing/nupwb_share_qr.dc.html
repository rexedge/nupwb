Code rules
Dark on white, always. Palm Green modules on pure white. Never gold on cream, never green on green, no gradient inside the modules — a scanner in a dim bar has no patience.
Quiet zone of 4 modules. Clean white on all four sides. The gold frame and Ankara border sit outside it, never over it.
Centre knockout, high error correction. The logo occupies the middle in a white circle, so the code is generated at level H — visibly denser modules than a plain code.
Encodes the URL only. Never a price, never an item. Prices change daily; the printed tents never do.
The code shown here is a visual placeholder at the correct module density and proportions — it is not scannable. Generate the real one at level H from menuSlug: "nwoke-udi", which the seed file marks immutable once these are printed.
