A price change is the most frequent admin action, so it never costs a navigation. Tap the figure, a numeric keypad docks over the tab bar, the rest of the list drops to 42% so the edited row is unmistakable, and the old value stays visible as “was ₦1,400” until save. The keypad carries a 00 key — every price on this menu ends in two zeros.

A brewery price rise moves thirty-odd beers at once, so bulk adjust is the second workflow after inline edit. Direction and unit are separate controls rather than a signed number — “−10%” typed wrong is a real cost. The preview line recomputes on every keystroke and states the item count, so the manager confirms the blast radius before applying, and the apply button repeats the count rather than saying “Apply”.
